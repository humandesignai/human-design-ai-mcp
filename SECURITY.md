# Security

Please do not open public issues containing credentials, OAuth tokens, signed asset URLs, private chart data, customer content, or suspected exploitable details.

Report security concerns through the support route at https://humandesignmcp.com/faq and clearly mark the message as a security report. Include reproduction steps with secrets removed.

The public repository contains connection metadata and workflow guidance only. The production MCP runtime remains separately operated and does not accept secrets through repository issues.
